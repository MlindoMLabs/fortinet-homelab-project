# fortinet-homelab-project

Fortinet Homelab Project

A hands-on Fortinet cybersecurity lab built using FortiGate VM, Kali Linux,
Ubuntu Server, Windows, and VirtualBox.

Objectives:
- Network Segmentation
- Firewall Administration
- VPN Technologies
- Threat Detection
- Web Filtering
- Malware Protection

Technologies:
- FortiGate 8.0
- Kali Linux
- Ubuntu Server
- Windows
- VirtualBox
